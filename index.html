Indian News Comparator

A Chrome extension that scores political bias in Indian news from −5 to +5 and explains why. News in India often frames the same event very differently depending on the outlet, and readers rarely see the other side. I built this for my second-year real-time research project to score how biased an article is and show the same story from other perspectives.

Version 1, Media Bias Extension, combined LLM analysis with retrieval to compare coverage. For version 2, I trained an IndicBERT and Liquid Neural Network classifier, then paired its scores with topic-filtered retrieval and Groq explanations.

65.4% accuracy on 3 classes (33% baseline), trained on 2,594 labelled articles.

What I built
  • The model training pipeline and bias classifier
  • The FastAPI backend and API design
  • Semantic retrieval with ChromaDB and topic-anchor filtering
  • LLM-generated explanations with Groq
  • Docker deployment and most of the Chrome extension
  • PyTorch
  • IndicBERT
  • FastAPI
  • ChromaDB
  • Groq
  • Docker
